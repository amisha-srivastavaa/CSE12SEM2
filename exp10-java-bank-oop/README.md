# Experiment 10: Java OOP Principles

This Java project demonstrates the core Object-Oriented Programming (OOP) principles:
- **Encapsulation:** Using `private` fields and public getter/setter methods.
- **Inheritance:** `SavingsAccount` and `CurrentAccount` inherit from `BankAccount`.
- **Abstraction:** The `BankAccount` class is `abstract` and contains an abstract method `calculateInterest()`.

## How to Run

1. Open a terminal and navigate to this folder:
   ```bash
   cd exp10-java-bank-oop
   ```
2. Compile the Java files:
   ```bash
   javac *.java
   ```
3. Run the Main class:
   ```bash
   java Main
   ```
