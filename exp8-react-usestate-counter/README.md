# Experiment 8: React useState Counter

This experiment demonstrates how to use the `useState` hook in React to manage and update state within a functional component.

## Requirements Covered
- Initialized a React app.
- Created a Counter component that starts at 0.
- Implemented Increment (+), Decrement (-), and Reset buttons.
- Used `useState` to manage the counter value.

## How to Run

1. Open your terminal and navigate to this folder:
   ```bash
   cd exp8-react-usestate-counter
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the provided `localhost` link in your browser to view the application.
