# React Student Management Dashboard

This is a modern, responsive Single Page Application (SPA) built with React and Vite. It serves as the frontend for managing student records.

## Features
- **Add Students:** Create new student records with validation.
- **Edit/Delete:** Update existing records or remove them.
- **State Management:** Uses React `useState` and `useEffect` hooks.
- **Styling:** Styled with Bootstrap 5 and custom CSS for a modern "dashboard" look.

## Prerequisites
- Node.js installed on your machine.

## How to Run

1. **Install Dependencies:**
   Run the following command to install required packages (`react`, `react-dom`, `bootstrap`, etc.):
   ```bash
   npm install
   ```

2. **Start Development Server:**
   Run the Vite development server:
   ```bash
   npm run dev
   ```

3. **View in Browser:**
   Open [http://localhost:5173](http://localhost:5173) (or the port specified by Vite in the console).

## Build for Production
To create a production-ready build:
```bash
npm run build
```
