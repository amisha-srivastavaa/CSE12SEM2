# Experiment 9: React Form Validation

This experiment demonstrates how to build forms in React, capture user input using `useState`, and perform client-side validation without needing a backend server.

## Requirements Covered
- Initialized a React app.
- Created a Registration Form with Name, Email, and Password.
- Managed form state using `useState`.
- Implemented validation rules:
  - Name cannot be empty.
  - Email must be in a valid format using Regex.
  - Password must be >= 6 characters.
- Displayed inline error messages.
- Showed a success message upon valid submission.

## How to Run

1. Open your terminal and navigate to this folder:
   ```bash
   cd exp9-react-form-validation
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the provided `localhost` link in your browser to view the application.
