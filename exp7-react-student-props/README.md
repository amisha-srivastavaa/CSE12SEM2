# Experiment 7: React Components & Props

This experiment demonstrates how to create a reusable React component (`Student.jsx`) and pass data into it using `props`.

## Requirements Covered
- Initialized a React app.
- Created a `Student` component that accepts `name`, `course`, and `marks` as props.
- Reused the component multiple times in `App.jsx` with different data.
- Applied basic custom CSS styling.

## How to Run

1. Open your terminal and navigate to this folder:
   ```bash
   cd exp7-react-student-props
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the provided `localhost` link in your browser to view the application.
